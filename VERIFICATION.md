# Результаты проверки проекта

Проверено 23 октября 2026 года. Окружение: Node.js **22.17.0**, npm **10.9.2**,
Vitest **3.2.7**, Vite **6.4.5**. Зависимости установлены отдельно в обоих проектах.
В манифестах указан Node.js 20+; выбранные версии Vitest и Vite поддерживают Node 20.
Фактические прогоны ниже выполнены на Node 22.17.0.

## Основные проверки

Команды выполнялись из корня проекта:

| Команда | Пройдено | Упало | Код выхода |
| --- | --- | --- | --- |
| `npm test --prefix student` | 2 | 0 | 0 |
| `npm test --prefix instructor` | 91 | 0 | 0 |
| `npm run test:student --prefix instructor` | 35 | 56 | 1 |

Код 1 в последней строке ожидаем: полный набор обнаруживает намеренные ошибки.
В нём отдельно подтверждено:

- оба теста `start.test.js` проходят на студенческой реализации;
- все восемь B1–B8 из `regressions.test.js` падают;
- падения вызваны нарушениями ожиданий и неверными исключениями, а не загрузкой модулей;
- в студенческом каталоге по-прежнему только один тестовый файл и два теста.

В 91 проверку входят 2 стартовых, 8 тестов-свидетелей и 81 расширенный сценарий.
Полный набор — это те же тестовые файлы, запускаемые против разных реализаций.
Загрузка ограничена `test/**/*.test.js`, поэтому временные проверки не попадают
в обычный инструкторский запуск, даже если запустить команды одновременно.

## Независимость восьми ошибок

Во временной копии исправленной реализации по очереди возвращалась **только одна**
ошибка. После каждой замены запускался `test/regressions.test.js` из восьми тестов.

| Возвращённая ошибка | Красный тест | Остальные семь |
| --- | --- | --- |
| `>=` заменён на `>` | B1 | Зелёные |
| boolean сравнивается со строкой `'true'` | B2 | Зелёные |
| Промокод переводится в верхний регистр | B3 | Зелёные |
| Льготы расположены перед экспрессом | B4 | Зелёные |
| В валидацию добавлено `!total` | B5 | Зелёные |
| Вход преобразуется через `Number(total)` вместо проверки типа | B6 | Зелёные |
| Для отрицательной суммы выбрасывается `TypeError` | B7 | Зелёные |
| Удалена проверка неизвестного типа доставки | B8 | Зелёные |

Это подтверждает, что тесты-свидетели не зависят от присутствия остальных дефектов.

## Репетиция мутационного этапа

В отдельной временной копии проведён эксперимент из `instructor/WORKSHOP.md`:

| Состояние | Пройдено | Упало |
| --- | --- | --- |
| Исправленная функция, полный набор | 91 | 0 |
| Мутация `>= 3000` → `> 3000`, только стартовые тесты | 2 | 0 |
| Та же мутация, полный набор | 89 | 2 |
| Восстановлено `>= 3000`, полный набор | 91 | 0 |

Мутацию обнаруживают B1 и строка таблицы стандартной доставки с суммой 3000.
Исходные файлы обеих версий при проверках не менялись; временные каталоги удалены.

## Целостность

- `node --check` прошёл для всех восьми JavaScript-файлов проекта.
- Проверены обязательные файлы, JSON-манифесты, наличие lock-файлов и локальные
  Markdown-ссылки на существующие материалы.
- Стартовые тесты в обеих версиях совпадают.
- `npm ls --depth=0` подтверждает установленный Vitest в обеих версиях.
- Функции используют ES Modules; общей инфраструктуры между проектами не требуется.

Для повторения основных проверок используйте команды выше. Для ручной репетиции
мутации следуйте этапу 60–70 минут в WORKSHOP.md и в конце верните правильный оператор.
