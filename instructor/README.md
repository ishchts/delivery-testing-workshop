# Материалы ведущего

Сначала прочитайте [WORKSHOP.md](WORKSHOP.md), затем [BUGS.md](BUGS.md).
Студентам передайте только соседний каталог `student/`.
Этот каталог самостоятельно запускается без студенческого проекта; соседняя
версия нужна только для дополнительной команды `test:student`.

## Подготовка

Требуются Node.js 20+ и npm. Выполните в каталоге этого README:

```sh
npm ci
npm test
npm test -- test/start.test.js
npm test -- test/regressions.test.js
npm run test:student
```

Обычный `npm test` запускает все тесты против исправленной реализации:
все должны пройти. `test/start.test.js` повторяет два исходных примера,
`test/regressions.test.js` содержит восемь коротких свидетелей ошибок B1–B8,
`test/calculateDelivery.test.js` расширяет проверки таблицами и сочетаниями.
Часть сценариев намеренно повторяется: короткие тесты служат картой ошибок,
таблицы показывают систематический подбор данных.

`npm run test:student` запускает **этот же полный набор** против текущего
`student/src/calculateDelivery.js` во временной копии. Исходные файлы обеих версий
сохраняются. В исходной студенческой версии проходят два стартовых теста,
а все восемь B1–B8 падают. Команда возвращает обычный код Vitest: **1** при
падениях, **0** после полного исправления. После запуска временная копия удаляется.
Команда требует наличия соседнего `student/`; исходные студенческие тесты она
не запускает и их количество не меняет.

```sh
npm run test:student -- -t 'B[1-8]:'
npm test -- -t 'B1:'
npm run test:watch
```

Для ожидаемых результатов, значений по умолчанию и порядка валидации используйте
контракт из `student/README.md`. В `src/calculateDelivery.js` уже находится
исправленный вариант. Правки во время основной практики делайте в `student/`.

Версии Vitest 3.2.7 и транзитивного Vite 6.4.5 закреплены для Node.js 20+.
Не обновляйте зависимости прямо перед занятием.
Справка: [Vitest 3](https://v3.vitest.dev/guide/) и
[`test.each()`](https://v3.vitest.dev/api/#test-each).

## Что подготовить на экране

- Основное окно редактора: только `student/`, README и стартовые тесты.
- Отдельное окно ведущего: этот каталог, BUGS и сценарий; не показывайте ответы заранее.
- Терминал студентов: `npm run test:watch` из `student/`.
- Запасной терминал ведущего: `npm test` из `instructor/`.
- Доска с колонками «вход → ожидание → правило → результат».

Запланируйте проверку установки до начала занятия. Для всей группы обсуждайте
падение одного теста за раз; собственные сценарии пары записывают до показа кода.
